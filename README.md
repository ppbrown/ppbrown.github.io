# [https://github.com/ppbrown](https://github.com/ppbrown)

I have many github repos. Some of them are "throwaway" ones, or temporary experiments.
The ones below, however, may be of interest to other people.

* [Container IDE](https://github.com/ppbrown/vscode-rancherdesktop-sampleworkflow) Bundled integration of vscode+rancher desktop to optimize developer workflow
* [VLM Utils](https://github.com/ppbrown/vlm-utils) (python) - Utilities that may be useful with Visual Language (AI) Models
* [AI Training](https://github.com/ppbrown/ai-training) (python) - Utilities for training an AI Model
* [Grafana Containerwatch](https://github.com/ppbrown/helm-grafana-containerwatch) Plugnplay stack to drop a container resource monitoring dashboard into your cluster
* [FluxCD Starer Kit](https://github.com/ppbrown/fluxcd-starterkit) My take on a full GitOps quickstart for [FluxCD](https://fluxcd.io/)
* [ArgoCD Demo](https://github.com/ppbrown/argocd-public-demo) (bash, argocd) - A CLI driven super-quick demo of [ArgoCD](https://argoproj.github.io/) for your own test k8s cluster
* [SOPS github Demo](https://github.com/ppbrown/gcp-sops-demo) - How to securely keep secret information in github
* [ZRep](https://github.com/bolthole/zrep/) (bash) - My ZFS based snapshot, backup, and recovery system
* [OneTrainerQt](https://github.com/ppbrown/OneTrainerQt) (python) - My port of the OneTrainer program to use Qt widgets instead of TkInter
* [ElasticSearch Utils](https://github.com/bolthole/elasticsearchutils) (bash) - CLI shortcut wrappers around a few useful ElasticSearch commands
